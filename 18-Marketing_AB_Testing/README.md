# 18 - Marketing A/B Testing Analysis

## Project Overview
Complete A/B test analysis project focused on a realistic Amazon-style experiment (new personalized recommendation banner).

This is one of the most valuable projects for Data Analyst and Business Analyst interviews at Amazon.

## What It Covers
- Experiment design simulation
- Conversion rate & AOV analysis
- Two-proportion Z-test + p-value
- 95% Confidence Intervals
- Relative & absolute lift
- Clear ship / no-ship recommendation framework

## How to Run
```bash
pip install -r requirements.txt
python analysis.py
```

## Outputs
- `01_ab_test_results.png`
- `02_order_value_distribution.png`
- `ab_test_raw_data.csv`
- `ab_test_summary.csv`
