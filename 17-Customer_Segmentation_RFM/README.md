# 17 - Customer Segmentation using RFM Analysis

## Project Overview
Professional RFM (Recency, Frequency, Monetary) customer segmentation project – one of the most commonly expected analyses for Data Analyst and Business Analyst roles at Amazon and other e-commerce companies.

## What You Will Find
- Realistic customer transaction data generation
- Classic RFM scoring (1-5 scale)
- Business-friendly segments (Champions, At Risk, Loyal, etc.)
- Clear visualizations + strategic recommendations for each segment

## How to Run
```bash
pip install -r requirements.txt
python analysis.py
```

## Outputs
- `01_rfm_segmentation.png`
- `02_rfm_heatmap.png`
- `customer_rfm_segments.csv`
- `segment_summary.csv`
- `sample_transactions.csv`

## Skills Shown
- Customer lifetime value thinking
- Segmentation strategy
- Data storytelling for marketing & CRM teams
- Actionable recommendations
