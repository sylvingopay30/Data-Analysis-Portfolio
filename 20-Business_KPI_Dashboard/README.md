# 20 - Business KPI Dashboard (E-commerce Executive View)

## Project Overview
Executive-level KPI dashboard project designed for Data Analyst and Business Analyst roles.

Tracks the most important e-commerce metrics Amazon cares about:
- Revenue, Orders, Sessions
- Conversion Rate
- Average Order Value (AOV)
- New vs Returning Customers
- Refund Rate
- Month-over-month performance

## How to Run
```bash
pip install -r requirements.txt
python analysis.py
```

## Outputs
- `01_kpi_dashboard.png` – Full multi-panel dashboard
- `02_funnel_snapshot.png`
- `daily_kpis.csv`
- `kpi_comparison.csv`

## Skills Demonstrated
- KPI definition & tracking
- Period-over-period analysis
- Executive storytelling
- Funnel thinking
- Clean visualization for leadership
