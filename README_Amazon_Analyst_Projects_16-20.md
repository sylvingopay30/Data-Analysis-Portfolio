# Amazon Data Analyst & Business Analyst Projects (16–20)

Five professional, portfolio-ready projects designed specifically for **Data Analyst** and **Business Analyst** roles at Amazon (and similar e-commerce / tech companies).

All projects are fully self-contained, generate professional visualizations, and include clear business insights and recommendations.

## Projects

| Folder | Project Name | Focus Area | Best For |
|--------|--------------|------------|----------|
| **16-Amazon_Sales_Analysis** | Amazon Sales Performance Analysis | Revenue, Category, Region, AOV, Discounts | Core DA skills |
| **17-Customer_Segmentation_RFM** | Customer Segmentation (RFM) | RFM scoring, Customer lifecycle, CRM strategy | Marketing / CRM analysis |
| **18-Marketing_AB_Testing** | Marketing A/B Testing | Experimentation, Statistical testing, Decision framework | Product & Growth teams |
| **19-Inventory_Demand_Analysis** | Inventory & Demand Analysis | Stock health, Days of Supply, Overstock/Stockout | Operations / Supply Chain |
| **20-Business_KPI_Dashboard** | Business KPI Dashboard | Executive metrics, Funnel, MoM performance | Leadership reporting |

## How to Run Any Project
```bash
cd <project-folder>
pip install -r requirements.txt
python analysis.py
```

Each project creates an `outputs/` folder containing:
- High-quality PNG visualizations
- CSV files (sample data + summaries)
- Clear printed insights and recommendations

- Focus on metrics Amazon actually cares about (Conversion, AOV, Retention, Inventory health, Experimentation)
- Strong business storytelling + recommendations
- Clean, readable code
