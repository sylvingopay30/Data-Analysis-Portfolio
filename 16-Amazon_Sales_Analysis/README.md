# 16 - Amazon Sales Performance Analysis

## Project Overview
End-to-end sales analysis project designed for **Data Analyst / Business Analyst** roles (Amazon, e-commerce).

The project simulates a realistic Amazon-like order dataset and delivers:
- Key business metrics (Revenue, AOV, Customers, etc.)
- Category & regional performance
- Shipping type impact
- Discount effectiveness
- Day-of-week seasonality
- Clear, actionable recommendations

## Why This Project Matters for Amazon
- Demonstrates ability to turn raw transactional data into business insights
- Shows comfort with large order-level data
- Focuses on metrics Amazon cares about (GMV, AOV, category mix, Prime impact)

## How to Run
```bash
pip install -r requirements.txt
python analysis.py
```

## Outputs
All results are saved in the `outputs/` folder:
- `01_sales_overview.png` – Monthly trend, category share, region, shipping
- `02_category_discount_analysis.png`
- `03_day_of_week.png`
- `key_metrics.csv`
- `sample_orders.csv`

## Skills Demonstrated
- Data generation & cleaning
- Aggregation & KPI calculation
- Professional visualization (matplotlib + seaborn)
- Business storytelling & recommendations
