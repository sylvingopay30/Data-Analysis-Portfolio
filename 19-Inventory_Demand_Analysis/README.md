# 19 - Inventory & Demand Analysis

## Project Overview
Inventory health and demand analysis project tailored for Operations Analyst / Business Analyst roles at Amazon.

Focus areas:
- Stock status classification (Healthy / Low / Stockout Risk / Overstock)
- Days of supply
- Inventory value by category
- Actionable recommendations for supply chain teams

## How to Run
```bash
pip install -r requirements.txt
python analysis.py
```

## Outputs
- `01_inventory_health.png`
- `02_status_by_category.png`
- `product_inventory.csv`
- `inventory_summary.csv`

## Skills Demonstrated
- Inventory metrics (Days of Supply, Reorder Point)
- Operational decision making
- Clear prioritization of actions
- Visualization of supply chain health
